# 架构与数据保留

`binary.mbt`/`writer.mbt`提供有界小端读写；`header.mbt`按LAS1.1–1.4读取公共头与扩展字节；`metadata.mbt`保留VLR结构；`point_read.mbt`/`point_write.mbt`处理全部0–10点格式。`evlr.mbt`管理点区后的扩展记录与波形绝对位置。未知结构不需先理解语义即可保留。

Document由Header、VLR数组、点前gap、Point数组与点后tail组成。波形引用保留UInt64，内存切片前检查范围。EVLR磁盘长度为64位，载入受Limits约束。Point额外字节保持原样，extra_bytes.mbt按VLR描述提供精确类型访问；projection.mbt汇总GeoTIFF/WKT等投影记录。

with_points是筛选/重编码共用的数据重建步骤：检查点字段、重算点数/回波/边界/记录宽度/点偏移，并将点区长度差同时应用于内部波形与EVLR绝对偏移。tail原样保留，因此点的波形相对偏移无需重写。with_evlrs重建扩展记录链，重算波形位置并保留链外字节；拒绝删除仍有点引用的内部波形。

encode使用同一重建路径，保留未知内容并规范化派生统计。它不是无需理解的文件拷贝器。merge严格检查元数据及相对尾部位置，禁止在未明确兼容的文件之间拼接波形内容。调用者确认CRS一致；本库的量化不是重投影。

质量统计、空间裁剪和网格使用线性扫描；网格采用有预算稠密矩阵。输入Bytes游标不建立全量Point数组，但保留输入，读取会复制记录；不提供磁盘流或零拷贝承诺。公开结构中的可变数组不能由其他任务并发修改。

默认64 MiB/100万点/4096记录/100万网格单元；所有外部长度、偏移与乘法在分配前检查。错误通过LasError返回。有限负scale可用，非有限坐标/GPS和无效字段拒绝。更多版本与能力边界见las-compatibility.md。

验证由84项测试、35份832点独立参考文档、2816属性组合、截断/偏移/预算测试及四个实际工作流组成。独立生成器固定laspy2.6.1、numpy2.2.6及随机种子；波形文件由独立struct布局并经laspy重新读取，筛选预期文件单独构建。没有性能优越性或安全认证声明。
