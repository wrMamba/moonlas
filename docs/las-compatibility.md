# LAS 格式兼容性与验证范围

0.2.0 将未压缩 LAS 1.4 全点格式及文件结构作为目标，兼容 1.1–1.3。实现范围与资源限制分别说明，避免把有限内存处理能力表述成任意大小文件支持。

|版本|点格式|标准公共头字节数|扩展记录|
|---|---|---|---|
|1.1|0–1|227|VLR|
|1.2|0–3|227|VLR|
|1.3|0–5|235|VLR、内部/外部波形|
|1.4|0–10|375|VLR、EVLR、内部/外部波形|

|格式|基础字节数|附加标准属性|
|---|---|---|
|0|20|旧格式基础属性|
|1|28|GPS|
|2|26|RGB|
|3|34|GPS、RGB|
|4|57|GPS、波形|
|5|63|GPS、RGB、波形|
|6|30|扩展分类/回波/扫描通道、GPS|
|7|36|格式6、RGB|
|8|38|格式7、NIR|
|9|59|格式6、波形|
|10|67|格式8、波形|

|标准结构/工作流|实现|验证|
|---|---|---|
|公共头、版本与格式、旧/扩展计数|header.mbt、encode.mbt|23组合，旧计数模式，负scale，损坏头|
|VLR、未知记录、保留字、固定文本、头扩展、gap|metadata.mbt、binary.mbt|独立文件及非规范文本 roundtrip|
|全部11点格式、点额外字节|point_read.mbt、point_write.mbt|736独立点与2816属性组合|
|64位EVLR磁盘长度、未知EVLR、尾部字节|evlr.mbt|70000字节记录、损坏长度、预算、完整字节对照|
|格式4/5/9/10、内部与外置WDP|waveform.mbt、waveform_access.mbt|12文档96点，8/16位样本与gain/offset|
|点区长度变化及波形非首EVLR|document.mbt、evlr.mbt|筛选后独立重建12个文件，完整字节比较|
|Extra Bytes类型0及1–30|extra_bytes.mbt|全部数值类型、向量、UInt64最大值、非法布局|
|GeoTIFF/WKT与未知投影记录保留|projection.mbt|VLR与EVLR混合、筛空后内容保留|

波形字节偏移以波形数据记录的60字节头起点为基准。LAS 1.3内部波形可在点区后独立存在；LAS 1.4波形记录可位于EVLR链中任意位置。外部WDP由调用者传入；包引用不经Double转换。压缩或未知波形编码保留原字节，样本解码返回Unsupported。

Extra Bytes 的 no-data/min/max 保留24字节类型联合；scale/offset提供为显式元数据，原始整数访问不损失精度。GeoTIFF/WKT提供原始记录获取和保留，不解析坐标变换语义。创建格式6–10数据时调用者应选择正确的WKT及global encoding；库不替调用者推断坐标系。

输入/输出默认64 MiB，最大配置1 GiB；点数和记录数受Limits约束。磁盘64位长度在转为内存索引前检查上限。库不实现LAS1.0、1.5、LAZ、磁盘流式IO、压缩波形解释或CRS重投影。派生统计在写出时重算，未知内容及结构位置按文档工作流保留；不宣称任意文件逐字节恒等或通过标准认证。

标准依据：[ASPRS LAS 1.4](https://github.com/ASPRSorg/LAS/tree/main-1.4)。字段实现和差分测试为本项目原创；laspy2.6.1用于独立构建和重新读取合成参考数据。波形容器与WDP由独立Python struct按标准构建，避免把MoonLAS输出当作自己的预期值。
